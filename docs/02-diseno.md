# Sistema de diseño

## Paleta

| Nombre | Hex | Uso |
|---|---|---|
| Fondo | `#E8F0EC` | Fondo general, verde agua calmado |
| Papel | `#FFFFFF` | Tarjetas y marcos de foto |
| Tinta | `#173A35` | Texto y botones principales |
| Tinta suave | `#3F5E58` | Texto secundario |
| Caléndula | `#F2B134` | Solo voz y logros |
| Línea | `#C3D3CC` | Bordes |

El texto principal sobre el fondo supera un contraste de 7:1 (WCAG AAA).

## Tipografía

**Atkinson Hyperlegible**, del Braille Institute, diseñada para baja visión.
Tamaños base: títulos de 30 a 38 px y cuerpo de 21 px. El usuario puede elegir
Normal, Grande (×1.15) o Enorme (×1.3).

## Elemento central: el botón de voz

Círculo caléndula de 132 px. Mientras escucha se vuelve verde pino con un halo
que respira, para que se note que está activo. Si el teléfono pide reducir
animaciones, el halo no se mueve.

## Reglas

- Botones de al menos 64 px de alto.
- Una acción principal por pantalla.
- La barra inferior tiene 3 secciones fijas.
- Las fotos llevan un marco blanco, como fotos impresas de álbum.
