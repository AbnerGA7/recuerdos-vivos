# Base del proyecto

Recuerdos Vivos es una app Android que usa fotos personales como punto de partida para preguntas guiadas sobre recuerdos.

## Propósito

Apoyar la estimulación cognitiva de personas con deterioro cognitivo, incluido Alzheimer, mediante la terapia de reminiscencia.

## Principios

- Un complemento, no un sustituto del tratamiento médico.
- Interfaz simple: botones grandes, textos cortos y alto contraste.
- Ningún elemento cambia de lugar sin aviso.
- Las fotos y el análisis se mantienen en el dispositivo.
