# Privacidad

- Las fotos se copian a la carpeta privada de la app.
- Recuerdos, respuestas y ajustes se guardan en un JSON en el teléfono.
- La app no tiene servidor ni cuentas.
- El reconocimiento de voz lo hace el servicio del teléfono. Según el
  teléfono, ese servicio puede usar internet; con el paquete de español
  descargado funciona sin conexión.
- Al borrar un recuerdo se borra su foto y sus sesiones.
